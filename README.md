# Vola ut Avis

A responsive fictional airline website built with HTML, CSS and vanilla JavaScript.

## Features

- Airline landing page with destination cards and FAQ
- Flight search by departure and arrival city
- Departure date and passenger validation
- Responsive flight results
- Demo flight summary with total fare calculation
- Keyboard-accessible native dialogs
- FAQ animation with reduced-motion support
- Hero slideshow with manual controls, autoplay and pause

## Run locally

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Start Live Server for `index.html`.

No package installation or build step is required.

## Demo limitations

All flights and fares are fictional and stored in a local JavaScript dataset.
The sample schedule repeats daily.

This project does not create reservations, sell tickets or process payments.

## Technologies

HTML, CSS, JavaScript ES modules, native dialog and details elements, and the Web Animations API.
